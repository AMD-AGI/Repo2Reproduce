# Repo2Reproduce
A grounded, agentic pipeline that turns a research paper + its GitHub code into a verified reproduction on AMD ROCm GPUs. Given a paper and repo, R2R reads both, selects the most reproducible experiment, extracts and reconciles the exact configuration (flagging paper-vs-code conflicts), and synthesizes the commands to run it — every claim backed by a verbatim paper quote or a real code reference. Its AMD track then ports the project to ROCm (base image, dependencies, and HIP migration of custom CUDA kernels, guarded by an integrity check that the ROCm PyTorch stack stays intact), builds it, and actually runs and measures the result on AMD hardware — producing an auditable report with the achieved metric versus the paper's target.
